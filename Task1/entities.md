Основные сущности

Сущность: Клиент
	Описание: Сущность отображает информацию о клиенте банка
	Основные атрибуты: 
		ФИО
		Дата рождения
		ИНН
		Паспортные данные (номер, серия, кем выдан, дата выдачи, код подраздедения, место рождения, адрес регистрации - ссылка на адресный реестр ) 
		СНИЛС
	Сущности с которым связана сущность: связи от клиента к сущностям нет, есть связи от других сущностях к данной (см. ниже)
	Системы-источники: ЕРК - единый реестр клиентов
	Критерии: Ключевая сущность, под который создается отдельный продукт
	Проблема качества - дубли, т.к один и тот же клиент заведен в разных системах. Нужна дедупликация
		
Сущность: Счет
	Описание: Сущность отображет информацию о счетах клиента
	Основные атрибуты: 
		Номер счета
		Сумма на счете
		Дата открытия счета
		Признак актуальности
		Дата закрытия счета 
		Ссылка на сущность "Клиент"
		Ссылка на сущность "Договор"
	Сущности с которым связана данная сущность: Клиент, Договор 
	Системы-источники: ЕРСК - единый реестр счетов и карт  
	Критерии: Ключевая сущность, которая относится к Клиенту, под которую создается отдельный продукт 
	Проблема качества: В AS IS разные счета привязаны к разным идентификаторам Клиента, т.е один и тот же клиент может быть в разных системах (см. проблематику по дублям в сущности Клиент) 

Сущность: Карта
	Описание: Сущность отображает информцию о карте клиента
	Основные атрибуты: 
		Номер карты 
		Тип карты
		Дата выдачи карты
		Срок окончания действия карты
		Признак актуальности 
		Тариф карты - ссылка на Справочник "Тарифы карт" 
		Ссылка на сущность "Счет" 
		Ссылка на сущность "Договор" 
	Сущности с которыми связана данная сущность: "Счет" , "Договор"
	Системы-источники: ЕРСК - единый реестр счетов и карт
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Проблема качества: в AS IS разные карты относятся к разным счетам, которые относятся к разным идентификаторам клиента (см. проблематику в дублировании Клиентов) 
	
Сущность: Кредит
	Описание: Сущность отображает информацию о кредите Клиента
	Основные атрибуты: 
		Ссылка на сущность "Договор" 
		Ссылка на сущность "Счет" - счет списания
		Дата списания кредита (дд.мм) 
		Ежемесячный платеж
		Оставшееся сумма кредита
		Ссылка на сущность "Продукт" 
		Тип кредита - ссылка на справочник "Типы кредитов"
		Признак актуальности
	Сущности с которым связана данная сущность: Договор, Счет, Продукт 
	Система-источники: Реестр кредитных историй - новый продукт
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Проблема качества: в AS IS разные карты относятся к разным счетам, которые относятся к разным идентификаторам клиента (см. проблематику в дублировании Клиентов) 

Сущность: Договор
	Описание: Сущность отображает информацию о договорах
	Основные атрибуты: 
		Ссылка на справочник "Типы договоров" 
		Дата начала действия договора
		Срок окончания действия договора
		Ссылка на PDF сканы договора 
		Ссылка на "Заявка""
		Признак актуальности 
	Сущности с которыми связана данная сущность: Заявка, + все сущности по которым выданы продукты банка, должны ссылаться на данную сущность (Кредит, Карта, Счет) 
	Система-источник: Договора и заявки - новый продукт в составе которого как и S3 так и posgreSQL, в S3 хранятся файлы сканов договоров, в БД postgreSQL хранится метаданные договора
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Проблематика: Подозреваю, что разные форматы данных в разных системах

Сущность: Заявка
	Описание: Сущность отображает информацию о заявках на предоставление кредитов
	Основные атрибуты: 
		Ссылка на справочник "Тип заявки" 
		Дата подачи заявки 
		Решение по заявке
		Дата закрытия заявки
		Ссылка на сущность "Продукт" 
		Автор заявки. Ссылка на сущность "Клиент"
		Признак актуальности
	Сущности с которыми связана данная сущность: "Клиент" , "Продукт"
	Система источник: Договора и заявки
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Проблематика: Подозреваю, что разные форматы данных в системах 
		
Сущность: Заемщик
	Описание: Сущность отображает информацию о заемщике по кредиту
	Основные атрибуты: 
		Ссылка на "Клиент"
		Перс. информация (в случае если ссылка на клиент не заполнена, т.е заемщик не является клиентом банка) 
	Сущности с которыми связана данная сущность: "Заемщик-Договор"
	Система источник: Договора и заявки
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Проблематика: Подозреваю, что разные форматы данных в системах. Но в документации на данный момент не вижу данной сущности вообще 
		
Транзакция
	Описание: Сущность отображает информацию о транзакции между счетами 
	Основные атрибуты: 
		Счет списания из текущего банка - Ссылка на "Счет" 
		Счет отправки в текущий банк - Ссылка на "Счет" (необязательный атрибут) 
		Счет отправки в другой банк - номер счета (обязательный атрибут) 
		Сумма
		Дата 
	Сущности с которым связана данная сущность: Счет 
	Система источник: История операция - новый продукт с новой БД на базе postgreSQL
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Проблематика:  Подозреваю, что разные форматы данных в системах. Но в документации на данный момент не вижу данной сущности вообще

Обращение клиента
	Описание: Сущность отображает информацию об обращении клиента в техподдержку
	Основные атрибуты: 
		Ссылка на сущность "Клиент" 
		Ссылка на справочник "тип обращения" 
		Сообщение
		Тема сообщения
		Дата сообщения
		Дата закрытия обращения
		Автор закрытия обращения
	Сущности с которыми связана данная сущность: Клиент
	Критерии: Сущность имеет свой ЖЦ + ключевая сущность для бизнеса
	Система-источник: Обращения клиентов - новый продукт с новой БД на базе postgreSQL
	
Продукт

	Основные атрибуты: 
		Ссылка на справочник "Тип продуктов" 
		Признак архивности
		Описание продукта
		Признак актуальности
	Сущности с которыми связана данная сущность: Тип продуктов
	Критерии: Сущность иммет свой ЖЦ + ключсевая сущность для бизнеса
	Система-источник: Реестр продуктов - новый продукт с новой БД postgreSQL 
	Проблематика:  Подозреваю, что разные форматы данных в системах. Но в документации на данный момент не вижу данной сущности вообще
	
Справочники
	Описание: Сущности описывают справочную информацию
	Основные атрибуты: 
		Код записи справочника
		Наименование записи справочника
		Признак актуальности 
	Сущности с которыми связана данная сущность: - 
	Критерии: Ключевая сущность для всех БП система 
	Система источник: НСИ - отдельный продукт для хранения справчоникав, для дальнешей синхронизации этих справочников с продуктами, которым справочники необходимы
	Проблематика: Подозреваю, что разные форматы данных в системах. Но в документации на данный момент не вижу данной сущности вообще
