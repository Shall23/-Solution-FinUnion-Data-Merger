Какие системы остаются? MDM, DWH, Lakehouse
Какие системы выводятся из эксплуатации? FU CRM, RB CRM, FU заимствование FinUnio, RB Заимствование RB Loans, FU Core Banking, RB Core Banking
Какие данные мигрируются? Данные по договорам, завкам, клиентам, счета и карты
Какие потоки переключаются? Все дублирующие продукты, по типу Карты FinUnion и Карты RB переключают свои потоки на общий продукт, куда будут сливаться данные из 2х продуктов банков + накладываться дедупликация. Такая же история с клиентами, счетами и т.п
Какие критерии подтверждают завершение перехода?
	Единая модель ключевых данных;
	Назначенные мастер-системы;
	Централизованный MDM для клиентских и справочных данных;
	Разделение OLTP и OLAP-нагрузок;
	DWH для регламентированной отчётности;
	Data Lakehouse для больших исторических и событийных данных;
	Каталог данных и lineage;
	Управляемые ETL/ELT-пайплайны;
	План отключения дублирующих legacy-систем RetailBank;
	Понятные правила владения данными;
	Целевые домены данных, согласованные с бизнес-областями и BIAN.
